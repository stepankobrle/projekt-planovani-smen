# Plánování směn

## Požadavky

- Node.js
- Vyplněný `backend/.env` (databáze, JWT secret, SMTP)

## Spuštění

```bash
# 1. Nainstaluj závislosti a připrav databázi
npm install
npm run setup

# 2. Spusť aplikaci
npm run dev
```

Frontend běží na [http://localhost:3000](http://localhost:3000), backend na [http://localhost:3001](http://localhost:3001).
